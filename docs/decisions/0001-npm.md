# 0001. npm вместо pnpm

**Статус:** принято, 2026-10-06.

**Контекст.** В спеке менеджер пакетов — pnpm. Главный плюс pnpm для нас — строгий `node_modules`: нельзя импортировать зависимость, которой нет в package.json. Но electron-builder плохо работает с симлинками pnpm, и для Electron его обычно переводят в `node-linker=hoisted`. В этом режиме строгость теряется. Остаются только минусы: pnpm нужно ставить отдельно и вручную разрешать install-скрипты.

**Решение.** npm. Он уже установлен вместе с Node.

**Последствия.**
- Команды: `npm run dev`, `npm test` и т. д. CLAUDE.md и spec.md обновлены.
- npm 12 по умолчанию блокирует install-скрипты зависимостей. Разрешения хранятся в `allowScripts` в package.json и меняются командой `npm install-scripts approve|deny`.
- Сейчас разрешён esbuild, а fsevents запрещён: у него есть готовый бинарник, а скрипт лишь пересобирает его через node-gyp.
- У Electron 44 install-скрипта нет: бинарник скачивается при первом запуске или командой `node node_modules/electron/install.js`.
