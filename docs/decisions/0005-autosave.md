# 0005. Автосохранение

**Статус:** принято, 2026-10-06.

**Решение.** Кнопки «Сохранить» в обычной работе нет. Проект хранится в памяти main и меняется только через `ProjectSession.update`. Каждое изменение сразу уходит в renderer, а на диск записывается через 500 мс после последнего изменения.

**Как устроено.**
- Запись атомарная: `project.json.tmp` + fsync, копия текущего файла в `project.json.bak`, затем rename.
- Записи никогда не идут параллельно. Изменение, сделанное во время записи, попадёт в следующую.
- Закрытие проекта, открытие другого и выход из приложения сначала дописывают несохранённое.
- Если запись не удалась, в панели появляется «Ошибка сохранения», а следующее изменение пробует снова. При закрытии или выходе приложение спрашивает, закрывать ли без сохранения.
- Пункт «Сохранить» (⌘S) остаётся: он дописывает изменения немедленно, не дожидаясь паузы.
- Открытие проекта само по себе ничего не пишет.

**Последствия.** Явной отмены «закрыть без сохранения» нет. Откат будет делать undo/redo на патчах (по спеке), а не отказ от сохранения.
